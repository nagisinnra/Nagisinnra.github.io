互換性情報（Compatibility）

NagisinnraLinux がどの PC で動作するかをまとめています。 ジャンクPC・古いノートPC・企業向けPCなど、幅広い環境で動作確認を行っています。

NEC

  • LAVIE（2012〜2020）… 起動・Wi-Fi・サウンド正常
  • 古い Celeron モデル … 起動はするが動作が重い

Dynabook（東芝）

  • 2013〜2019年モデル … 問題なし
  • 一部の Realtek Wi-Fi … ドライバ追加が必要

富士通（FMV）

  • LIFEBOOK シリーズ … 起動・Wi-Fi・サウンド正常
  • 古いモデル … UEFI 設定変更が必要な場合あり

Lenovo

  • ThinkPad シリーズ … Linux との相性が非常に良い
  • IdeaPad … 基本的に問題なし

CFD（玄人志向）

  • SSD / NVMe … 完全対応
  • メモリ … 問題なし

その他の環境

  • VirtualBox / VMware / QEMU … 動作確認済み
  • 古いジャンクPC … 軽量モードで動作可能
  • 32bit CPU … 非対応

互換性に問題がある場合

→ サポートページ を参照してください。 Wi-Fi・画面表示・起動トラブルなどの対処法を掲載しています。
