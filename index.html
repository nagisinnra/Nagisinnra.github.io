NagisinnraLinux

13歳が開発した、日常使いのためのDebianベース超軽量Linux
Version: v1.0.2 stable Released: 2026.08 Architecture: x86_64

主な特徴 (Features)

超軽量設計

起動直後のRAM使用量: 約476MB

ディスク使用量: 約2.45GB

快適な日本語環境

軽量化と日本語入力を両立するため、fcitx5 + mozc を初期状態で標準搭載。

メモリ最適化

少ないメモリでも快適に動作するよう、zramによるメモリ圧縮技術を最適化構成。

技術情報 (Technical Details)

  • Base Distribution: Debian GNU/Linux
  • Memory Optimization: zram
  • Input Framework: fcitx5
  • Input Method: mozc
