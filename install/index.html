Install NagisinnraLinux.

NagisinnraLinux のインストール方法を紹介します。 USBメディアの作成から初回起動まで、順番に進めていきましょう。

このガイドでは、一般的なPCへのインストール手順を説明します。 作業を始める前に、必要なものを確認してください。

Installation process

以下の6つのステップでインストールできます。

01

必要なものを準備する

インストールを始める前に、以下のものを用意します。

  • USBメモリ（8GB以上推奨）
  • NagisinnraLinux の ISO イメージ
  • USB書き込みツール（Rufus / balenaEtcher など）
  • インターネット接続環境（必要に応じて）
02

ISO イメージをダウンロードする

ダウンロードページから NagisinnraLinux の ISO イメージを取得します。

Download NagisinnraLinux →
03

USB ブートメディアを作成する

Windows の場合（Rufus）

  • Rufus を起動する
  • 書き込み先の USB メモリを選択する
  • 「選択」から ISO イメージを指定する
  • ISO の起動方式に合わせて設定する
  • 「スタート」を押して書き込みを開始する

macOS / Linux の場合（balenaEtcher）

  • balenaEtcher を起動する
  • ISO イメージを選択する
  • 書き込み先の USB メモリを選択する
  • 「Flash」を押して書き込みを開始する
USBメモリ内のデータは消去されます。必要なデータは事前にバックアップしてください。
04

PC を USB から起動する

作成した USB メモリをPCに接続し、USBから起動します。

  • PCの電源を切り、USBメモリを接続する
  • 電源を入れ、起動直後にブートメニューを開く
  • USBメモリを選択する
  • NagisinnraLinux の起動を確認する
ブートメニューのキーはメーカーによって異なります。 F12、ESC、F2 などが使用される場合があります。
05

インストーラーを操作する

起動後、インストーラーの案内に従って設定を進めます。

  • 「Install NagisinnraLinux」を選択する
  • 言語・キーボードを設定する
  • インストール先のディスクを選択する
  • ユーザー名・パスワードを設定する
  • 設定内容を確認してインストールを開始する
インストール先ディスクの選択には注意してください。 ディスク内の既存データが消去される場合があります。 必要なデータは必ず事前にバックアップしてください。
06

インストール完了

インストールが完了したら、次の手順で起動します。

  • 画面の案内に従ってPCを再起動する
  • USBメモリを取り外す
  • PCが内蔵ディスクから起動することを確認する

NagisinnraLinux のデスクトップが表示されれば完了です。

インストール前の注意事項

OSのインストールは、既存のデータやOSに影響する場合があります。 大切なファイルは必ずバックアップしてください。 また、PCによってBIOS / UEFIの設定や起動方法が異なります。

Need help?

インストール中に問題が発生した場合は、サポートページをご確認ください。
