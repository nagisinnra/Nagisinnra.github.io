NagisinnraLinux インストールガイド

NagisinnraLinux を PC にインストールするための手順をまとめています。 USB ブートの作成からインストール完了まで、初心者でも迷わないように構成しています。

1. 必要なもの

  • USBメモリ（8GB以上推奨）
  • NagisinnraLinux の ISO イメージ
  • USB書き込みツール（Rufus / balenaEtcher など）

2. ISO をダウンロードする

最新の ISO は以下からダウンロードできます。 → ダウンロードページへ

3. USB ブートメディアを作成する

Windows の場合（Rufus 推奨）

  • Rufus を起動
  • USBメモリを選択
  • 「選択」から ISO を指定
  • パーティション：MBR / ターゲット：BIOS or UEFI
  • 「スタート」を押す

macOS / Linux の場合（balenaEtcher 推奨）

  • Etcher を起動
  • ISO を選択
  • USB を選択
  • 「Flash」を押す

4. PC を USB から起動する

  • PC の電源を入れる
  • 起動直後に F12 / ESC / F2 などを押してブートメニューへ
  • USB を選択して起動

5. インストーラーの操作

  • 「Install NagisinnraLinux」を選択
  • 言語・キーボードを選択
  • インストール先ディスクを選択
  • ユーザー名・パスワードを設定
  • インストール開始

6. インストール完了後

  • USB を抜く
  • PC を再起動
  • NagisinnraLinux が起動すれば成功

トラブルが起きたら

→ サポートページへ 起動しない・Wi-Fiが繋がらないなどの対処法を掲載しています。
