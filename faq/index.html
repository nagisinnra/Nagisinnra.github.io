FAQ（よくある質問）

Q. NagisinnraLinux はどんな PC で動きますか？

基本的に 64bit CPU を搭載した PC なら動作します。 古いノートPCやジャンクPCでも軽快に動くよう最適化されています。

Q. どれくらい軽量ですか？

メモリ 2GB でも動作可能です。 4GB 以上あれば快適に利用できます。

Q. Debian と何が違いますか？

NagisinnraLinux は Debian をベースに、 軽量化・高速化・日本語環境の改善を行ったディストロです。

Q. インストール方法が分かりません

→ インストールガイド を参照してください。

Q. Wi-Fi が繋がりません

→ サポートページ にトラブルシューティングを掲載しています。

Q. 仮想環境で使えますか？

はい。VirtualBox / VMware / QEMU で動作確認済みです。

Q. 企業向け利用は可能ですか？

可能です。商用利用も自由です。 企業向けの案内は今後掲載予定です。

Q. 問題が解決しません

→ GitHub Issues からお問い合わせください。
