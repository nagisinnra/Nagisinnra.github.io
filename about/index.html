About the project

Technology should
be accessible to everyone.

NagisinnraLinux は、古いPCにも新しい可能性を与えることを目指して 開発されている Debian ベースの Linux ディストリビューションです。 軽量性、使いやすさ、日本語環境を大切にしています。

Debian Based Lightweight Linux Japan Open Source

NagisinnraLinux は、限られたハードウェア資源でも快適に利用できる デスクトップ環境を目指すプロジェクトです。 古いノートPCや低スペックPCの再活用から、日常的なコンピューター利用まで、 幅広い用途を想定して開発しています。

Our mission

プロジェクトが大切にしている4つの考え方。

01 / ACCESSIBILITY

古いPCに新しい可能性を

まだ使えるハードウェアを活用し、 コンピューターをより長く使える環境を提供します。

02 / PERFORMANCE

軽量で快適な環境

不必要な負荷を抑え、限られたリソースでも 快適に動作するデスクトップを目指します。

03 / LOCALIZATION

使いやすい日本語環境

日本語入力や表示環境を整え、 日本のユーザーが使いやすい環境を目指します。

04 / OPEN SOURCE

オープンな開発

オープンソースの考え方を尊重し、 より多くの人が利用・参加できるプロジェクトを目指します。

Key features

NagisinnraLinux の主な特徴。

Lightweight Desktop

軽量なデスクトップ環境を採用し、 古いPCや低スペックPCでの利用を考慮しています。

Japanese Environment

日本語表示や日本語入力に対応した環境を提供します。

Debian Foundation

Debian をベースに構築し、 そのパッケージエコシステムを活用しています。

Virtualization Support

VirtualBox、VMware、QEMU などの 仮想環境での動作も想定しています。
